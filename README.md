## Featured projects

### 🚤 [FGCU Water School Fleet Management System](https://github.com/BEN-Ammar-Ahmed/fgcu-water-school-fleet-demowebsite)
Software for a real campus client. Two Flask + PostgreSQL web apps: a staff fleet site (vehicles, maintenance, trips, fuel, documents, spending stats) and a public vehicle request site with an approval workflow and email notifications.
- 3-tier role-based access, CSRF protection and a full activity audit log
- Spreadsheet import with column matching, duplicate detection and all-or-nothing saves
- **255 automated tests**, Lighthouse 100 for accessibility, a no-SQL handover guide for staff
- Team project (4 people); I built both web apps

`Python` `Flask` `PostgreSQL` `Supabase` `Docker` `pytest`

### 🩺 [InsureBased](https://github.com/BEN-Ammar-Ahmed/insurebased) · [live demo](https://doct-lookup.vercel.app)
Find doctors by ZIP code, specialty and insurance, using public NPI Registry and CMS Marketplace data, with interactive maps.
- Bulk data ingestion into PostgreSQL and a shared Redis rate limiter with a safe fallback
- **~175 unit and Playwright end-to-end tests** in a GitHub Actions pipeline

`Next.js` `React` `TypeScript` `PostgreSQL` `Redis` `Leaflet` `Playwright`

### 🤖 [NOVA](https://github.com/BEN-Ammar-Ahmed/Nova) + [VALO](https://github.com/BEN-Ammar-Ahmed/valo)
A voice-first AI desktop agent for Windows that controls the desktop, works with files and notes, searches the web and handles email and calendar through LLM tool calling.
- Privacy-aware model routing: local Ollama models for private tasks, cloud models for real-time voice and vision
- Class Capture: lecture transcription, speaker-role mapping and student-question detection
- **VALO**, its desktop shell: a native Tauri app with live-data widgets

`Python` `LiveKit Agents` `Gemini Realtime` `Groq` `Ollama` `Tauri`
