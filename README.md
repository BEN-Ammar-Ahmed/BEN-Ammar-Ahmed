## 🩺 InsureBased

### Healthcare Provider Discovery Platform

A modern healthcare provider search application designed to help users find providers using location, specialty, insurance information, and official healthcare datasets.

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github)](https://github.com/BEN-Ammar-Ahmed/Doct-lookup)

**Highlights**

- Provider search using public healthcare data
- Insurance-aware coverage logic
- Interactive provider maps
- Provider detail pages
- Location and address matching
- Responsive mobile experience
- PostgreSQL-backed data pipeline support
- Rate limiting and production protections
- Automated testing
- Accessibility and error-state handling
- Production deployment architecture

**Built with**

`Next.js` · `React` · `TypeScript` · `PostgreSQL` · `Leaflet` · `Node.js` · `Playwright` · `Vercel`

## 🤖 NOVA

### Intelligent Desktop Assistant

NOVA is an experimental desktop AI assistant designed around the idea that an AI should be able to understand and interact with the user's computer environment.

```text
Voice
  ↓
AI Reasoning
  ↓
Context + Screen Awareness
  ↓
Local Tools
  ↓
Desktop Actions
```

**Core concepts**

- Voice interaction
- Screen understanding
- Local application control
- AI tool calling
- Context-aware workflows
- Notes and file interaction
- Class transcription and capture
- Local AI model support
- Desktop automation

**Technologies explored**

`Python` · `Gemini` · `Groq` · `Ollama` · `Whisper` · `Automation APIs`

> Currently evolving as an experimental AI systems project.
